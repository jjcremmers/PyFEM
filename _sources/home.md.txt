# PyFEM Documentation

PyFEM is an open-source finite element code for teaching, research, and
prototyping in computational solid mechanics. It accompanies the textbook
[Non-Linear Finite Element Analysis of Solids and Structures](https://www.wiley.com/en-us/Nonlinear+Finite+Element+Analysis+of+Solids+and+Structures%2C+2nd+Edition-p-9780470666449)
by R. de Borst, M.A. Crisfield, J.J.C. Remmers, and C.V. Verhoosel. The book
provides the theoretical background, while PyFEM provides executable
implementations and examples of the methods discussed there.

Start with the [introduction](introduction/introduction.md), follow the
[installation guide](installation/installation.md), or go directly to the
[quickstart](introduction/quickstart.md). The remaining sections describe the
available elements, materials, models, solvers, input/output modules, and
development conventions.
