# User Manual

This user manual provides comprehensive documentation for PyFEM's main components. Use the sections below to find detailed information about elements, materials, solvers, input/output modules, and tutorials.

The following chapters describe the available element formulations, material
models, solvers, and input/output modules. Each chapter includes parameter
descriptions, usage examples, and cross-references to help you build and run
your finite element analyses.
