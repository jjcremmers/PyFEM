ViscoPlasticity

ViscoPlasticity is a rate-dependent plasticity model based on Perzyna overstress theory. It combines isotropic elasticity with von Mises yielding, viscoplastic flow above the yield stress, and optional linear hardening.

Warning

This page was generated with the assistance of AI and must be checked carefully against the implementation and the conventions of the element being used.

Input parameters

material =
{
  type   = "ViscoPlasticity";
  E      = 200000.0;
  nu     = 0.3;
  syield = 250.0;
  gamma  = 0.001;
  n      = 1.0;
  hard   = 1000.0;
};
