Dummy

Dummy is a simple linear traction law intended primarily for testing interface elements. It applies the same scalar stiffness D to the normal and tangential components of the interface displacement jump. It is useful for verification and basic interface experiments, but it does not represent a physical cohesive failure law.

Overview

  • Material type: Dummy

  • Application: interface-element testing

  • Supported dimensions: 2D and 3D interface elements

  • Traction output: Tn, Ts in 2D; Tn, Ts1, Ts2 in 3D

The material uses the interface displacement jump as its deformation vector and computes traction as

\[\boldsymbol{t} = \boldsymbol{H}\,\boldsymbol{\delta}, \qquad \boldsymbol{H} = D\boldsymbol{I}.\]

The tangent is constant and diagonal. No damage, softening, or failure evolution is included.

Input parameters

material =
{
  type = "Dummy";
  D    = 1.0e5;
};
