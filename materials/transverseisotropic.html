TransverseIsotropic

TransverseIsotropic is a three-dimensional linear-elastic material model for unidirectional composites with one preferred material direction. The material uses E1 in the preferred direction, E2 in the transverse directions, and the shear modulus G12 for the shear terms.

Overview

  • Material type: TransverseIsotropic

  • Kinematics: three-dimensional linear elasticity

  • Stress output: S11, S22, S33, S23, S13, S12

  • Formulation: total strain by default

The stress and strain vectors use the Voigt ordering

[S11, S22, S33, S23, S13, S12]

The preferred material direction is component 1. Components 2 and 3 define the transverse plane. The implementation returns a constant six-by-six constitutive matrix as the material tangent.

Constitutive response

The stress is computed from the strain vector as

\[\boldsymbol{\sigma} = \boldsymbol{H}\,\boldsymbol{\varepsilon}.\]

The normal-stress block is determined by E1, E2, and nu12. The three shear entries of the implemented matrix are set to G12:

\[H_{44} = H_{55} = H_{66} = G_{12}.\]

The material assumes that the material axes are aligned with the element coordinate system. Verify this assumption before using the model for rotated laminae or general composite layups.

Input parameters

material =
{
  type = "TransverseIsotropic";
  E1   = 135.0;
  E2   = 10.0;
  nu12 = 0.3;
  G12  = 5.0;
};
