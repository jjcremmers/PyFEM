# PyFEM documentation

Sphinx sources in this directory. Build after installing the package:

```bash
uv sync --extra docs
uv run --no-sync sphinx-build -b html doc doc/_build/html
```

Output: `doc/_build/html/index.html`

CI and Read the Docs use the same documentation extra. To install contributor tools as well, add `--extra dev` to `uv sync`.

The API reference is generated by `sphinx-autoapi` during the Sphinx build.

## Hosting

- **Read the Docs (primary):** https://pyfem.readthedocs.io/
- **GitHub Pages (mirror):** built in CI and published from `main` with GitHub's Pages deployment actions. Set repository **Settings → Pages → Build and deployment → Source** to **GitHub Actions** when merging this workflow.

## Linux note

Doc builds may require `libgl1` because Sphinx imports VTK-related modules. CI and RTD install it via apt.
