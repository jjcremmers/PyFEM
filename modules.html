Modules

PyFEM provides solver and input/output modules that manage the execution of analyses and the exchange of model and results data.

Introduction

The modules described in this chapter are configured through PyFEM input files and can be combined to build complete analyses. Solvers advance the solution, while I/O modules read input data and write results for post-processing.
