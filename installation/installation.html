PyFEM Installation

PyFEM currently supports Python 3.9 through 3.14, as well as pip and Git. The commands below install PyFEM from the source repository and create the pyfem command-line tool.

Warning

Python 3.15 is not supported. Do not continue if the selected interpreter is Python 3.15. PyFEM or one of its dependencies may not yet be compatible with that version. Use Python 3.9–3.14 instead.

Quick installation

If you want to use PyFEM to run your own finite element simulations but do not plan to develop new features, this quick installation guide is for you.

Windows (Command Prompt)

Open Command Prompt (cmd.exe) and run:

git clone https://github.com/jjcremmers/PyFEM.git
cd PyFEM
py -c "import sys; raise SystemExit('Python 3.15 is not supported; use Python 3.9-3.14.') if sys.version_info[:2] == (3, 15) else None"
py -m venv pyfem-env
pyfem-env\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install .

Install Python 3.9 through 3.14 from python.org and Git from git-scm.com if they are not already available. When installing Python, enable Add Python to PATH.

Linux or WSL

In a terminal (or a WSL shell), run:

git clone https://github.com/jjcremmers/PyFEM.git
cd PyFEM
python3 -c 'import sys; raise SystemExit("Python 3.15 is not supported; use Python 3.9-3.14.") if sys.version_info[:2] == (3, 15) else None'
python3 -m venv pyfem-env
source pyfem-env/bin/activate
python -m pip install --upgrade pip
python -m pip install .

On Debian or Ubuntu, install the system prerequisites first if necessary:

sudo apt-get update
sudo apt-get install python3 python3-venv python3-pip git

macOS

In Terminal, run:

git clone https://github.com/jjcremmers/PyFEM.git
cd PyFEM
python3 -c 'import sys; raise SystemExit("Python 3.15 is not supported; use Python 3.9-3.14.") if sys.version_info[:2] == (3, 15) else None'
python3 -m venv pyfem-env
source pyfem-env/bin/activate
python -m pip install --upgrade pip
python -m pip install .

If Python or Git is not installed, install them with Homebrew:

brew install python git

Advanced installation

The virtual environment should be activated before running the commands in this section. The core installation includes VTK output support. The GUI is optional; install it with the gui extra. The all extra installs all optional dependencies.

Windows (Command Prompt)

For an editable development installation, changes to the source are available without reinstalling:

cd PyFEM
pyfem-env\Scripts\activate.bat
python -m pip install -e ".[dev]"

For GUI support use python -m pip install -e ".[dev,all]". To install the latest source directly from GitHub instead:

python -m pip install git+https://github.com/jjcremmers/PyFEM.git

Linux or WSL

For an editable development installation, changes to the source are available without reinstalling:

cd PyFEM
source pyfem-env/bin/activate
python -m pip install -e ".[dev]"

For GUI support use python -m pip install -e ".[dev,all]". To install the latest source directly from GitHub instead:

python -m pip install git+https://github.com/jjcremmers/PyFEM.git

On headless Linux systems, GUI or VTK issues may require:

sudo apt-get install libgl1-mesa-glx libxkbcommon-x11-0

macOS

For an editable development installation, changes to the source are available without reinstalling:

cd PyFEM
source pyfem-env/bin/activate
python -m pip install -e ".[dev]"

For GUI support use python -m pip install -e ".[dev,all]". To install the latest source directly from GitHub instead:

python -m pip install git+https://github.com/jjcremmers/PyFEM.git

If graphical applications require it, install XQuartz:

brew install --cask xquartz

Verify the installation

With the virtual environment active, run:

pyfem --version
pyfem --help

You can also run an example from the repository:

cd examples/ch02
pyfem PatchTest8.pro

To verify the Python API:

from pyfem import run

results = run("examples/ch02/PatchTest8.pro")
print(results["globdat"].state)

Run the unit tests

The development dependencies include pytest and coverage. If you have not installed them yet, activate the virtual environment and run:

python -m pip install -e ".[dev]"

PyFEM also provides shortcuts through the pyfem command:

pyfem -test       # Run the unit tests
pyfem -coverage   # Run tests, print coverage, and create an HTML report

Both commands create the HTML report at htmlcov/index.html, which can be opened in a browser. The -coverage shortcut also prints the coverage summary in the terminal.

Updating, uninstalling, and troubleshooting

From the cloned repository, update an existing installation with:

git pull origin main
python -m pip install --upgrade .

Uninstall PyFEM with:

python -m pip uninstall pyfem

If pyfem cannot be found, activate pyfem-env again. On Linux or macOS, which pyfem shows the executable location; on Windows Command Prompt, use where pyfem. For a broken installation, reinstall it with:

python -m pip install --force-reinstall .
